BatchPrint 1.0 · macOS 14 or later

BatchPrint Support

A macOS PDF batch printing utility. Add your PDFs, arrange them in order, and submit them to a printer using the native macOS printing system.

PDF only. BatchPrint 1.0 does not directly open Word, Excel, or PowerPoint files, and does not support batch export using Save as PDF.

Getting started

  1. Add your PDFs

    Click Add PDFs and select multiple PDF files in the file picker, or drag PDF files from Finder into the BatchPrint window. Duplicate files are not added again.

  2. Arrange the printing order

    Use Move Up or Move Down on a file row or in its context menu. You can also drag rows to reorder them. Files are submitted in the order shown in the queue.

  3. Preview a PDF

    Choose Preview from the file row or its context menu. You can also select a single file in the queue and press the Space bar. Use the preview window to change pages, zoom, or fit the page.

  4. Choose your printer and settings

    Click Print All. In the macOS print panel, select a configured physical printer and review the paper size, orientation, and other available printer options. Confirm to begin submitting jobs.

    The settings panel appears once for the batch. Subsequent PDFs reuse those settings. Available options depend on macOS and your printer driver.

  5. Check the print queue

    Submitted means the job was handed to the macOS printing system. It does not mean the printer has finished printing. Use the macOS printer queue to check the printer's progress or cancel jobs that have already been submitted.

Managing the queue

  • Remove: removes a file from BatchPrint's list without deleting the original PDF.
  • Clear All: choose this in the queue actions menu and confirm to remove all files from the app. Jobs already submitted to macOS are not canceled.
  • Cancel Queue: stops submitting remaining files after the current file. It does not cancel jobs already handed to macOS.
  • Retry: click Print All again after resolving a problem. Files already marked Submitted are skipped.
  • Reset Queue: makes files eligible for printing again, including files marked Submitted. Existing jobs stay in the macOS print queue, so resetting and printing again may produce duplicate copies.

Adding, reordering, removing, resetting, and clearing are unavailable while a batch is being submitted.

Common questions & troubleshooting

Can I print Word, Excel, or PowerPoint files?

BatchPrint 1.0 accepts PDF files only. Export your document to PDF from its original application, check that PDF, and then add it to BatchPrint.

Can I choose Save as PDF or Preview in the print panel?

No. BatchPrint 1.0 submits batches to physical printers; it does not offer batch PDF export or the print panel's Preview destination. If no jobs have been submitted in the attempt, an unsupported destination leaves the remaining PDFs Ready so you can select a printer and try again. The app's own file preview is available before printing.

My printer is missing, paused, or unavailable.

Check System Settings > Printers & Scanners. Make sure the printer is configured, powered on, connected, and not paused. Check its macOS queue and any driver or manufacturer guidance before retrying.

Compatibility depends on your printer, driver, supported paper sizes, and macOS configuration. BatchPrint does not guarantee compatibility with every printer.

A PDF cannot be opened or added.

Confirm that the file is a readable PDF with at least one page. If it has been moved, deleted, or its access permission has expired, remove the entry and add the file again. A damaged file may need to be re-exported from its original application. Password-protected PDFs cannot be opened by BatchPrint's preview.

The paper size is unsupported or content does not fit.

Choose a paper size supported by your printer, such as A4 or Letter, in the print panel. BatchPrint fits PDF content within the printer's reported printable area without enlarging smaller pages. Check the PDF itself: content outside its CropBox is not restored by paper fitting.

A file shows Failed and later files show Canceled.

A submission error stops the remaining queue. Check the error shown for the failed file, the printer connection, and the macOS printer queue. After resolving the issue, click Print All to retry files that have not been submitted. Previously submitted jobs remain in macOS and are skipped.

Files show Submitted but nothing has printed.

Open the macOS printer queue. A job may be waiting, paused, or blocked by a printer problem such as missing paper. Submitted confirms acceptance by macOS, not physical printing completion. Avoid resetting and resubmitting until you have checked for existing jobs.
