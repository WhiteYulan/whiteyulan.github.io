BatchPrint Privacy Policy

How BatchPrint handles your PDFs and print jobs.

BatchPrint 1.0 does not collect personal data or upload your PDFs to a developer-operated server. Your documents are processed on your Mac and handed to macOS when you choose to print.

1. Introduction

This policy describes the BatchPrint 1.0 macOS application and distinguishes its behavior from the services used to distribute the app, print documents, or host these support pages.

BatchPrint is a PDF batch printing utility. It uses Apple's native frameworks to read and preview PDFs and the macOS printing system to submit print jobs.

2. Information We Collect

The BatchPrint 1.0 app does not collect or transmit personal information, PDF contents, or usage analytics to the developer. It has no user accounts, advertising SDKs, or analytics SDKs.

If you voluntarily email support, your email address and the information you include are received as support correspondence and used to respond to your request. This is separate from using the app. Please avoid sending confidential documents or unnecessary personal information.

BatchPrint writes local diagnostic messages through macOS logging, including print operation status, error information, and paper-layout information. It does not include an automatic log-upload feature.

3. PDF File Processing

BatchPrint reads the PDF files you choose on your device to determine their page counts, display previews, and prepare printable pages. Queue entries contain local file references, filenames, page counts, and job status while the app is running.

The app does not provide server-side PDF processing or a document-upload feature. Previewing or removing an item from the app's queue does not modify or delete your original PDF.

If a file is stored in iCloud Drive, a network location, or another file provider, accessing that file may involve services managed by macOS or that provider. BatchPrint does not operate those services.

4. Printing and System Permissions

When you confirm printing, BatchPrint passes document content and print settings to the macOS printing system for the printer you selected. A job title may contain the PDF's filename. macOS and the printer may retain or process print jobs according to their own queue, spool, driver, and device behavior.

A network printer may receive document data over a network through the system printing workflow. This is not an upload to a BatchPrint server. BatchPrint's app code does not implement a separate web-request or cloud-upload service.

BatchPrint uses App Sandbox, permission to access user-selected files, and the Printing entitlement. File access is obtained through the system file picker or files you drag into the app, rather than unrestricted access to all your documents.

Clearing the BatchPrint queue does not remove jobs already submitted to macOS. To manage or cancel those jobs, use the macOS printer queue. The app's Submitted status does not confirm physical printing completion.

5. Third-Party Services

The app uses Apple system frameworks and does not embed third-party advertising or analytics services. Apple, your printer manufacturer, and any file provider you choose operate their own services under their own policies.

These support and privacy pages are hosted on GitHub Pages. GitHub states that it logs visitors' IP addresses for security purposes. See GitHub Pages data collection and the GitHub Privacy Statement.

Our page code contains no analytics or advertising scripts, external font services, or cookies. Visiting the website is separate from the BatchPrint app's local PDF processing.

6. Data Security

Local processing and macOS sandbox permissions limit the app's access to your documents. No software or printing workflow can guarantee absolute security. The security of your Mac, chosen file locations, printer connection, printer storage, and support email also matters.

Use printers and file locations you trust, keep macOS and printer software up to date, and avoid including sensitive document contents in support messages.

7. Changes to This Policy

This policy describes version 1.0. If the app's data practices change, this page will be updated with a revised date and the applicable app privacy disclosures will be reviewed.
